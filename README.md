# Project Shooter

This Xiao and Partho's C++ T2 project.

## How to Setup

* Ensure you have Visual Studio 2022.
* Run `git clone https://github.com/parthoghosh24/XPStudios.git` to clone this project locally.
* Download SFML from [here](https://www.sfml-dev.org/download/sfml/3.1.0/). Ensure the version but it should be ideally the 64 bit one.
* Unzip and get the SFML-3.x.x folder, copy it to `XPStudios/ProjectShoot/ThirdParty`.
* Rename `SFML-3.x.x` to `SFML`.
* Open the project into Visual Studio 2022. You can right click and open in visual studio within `ProjectShoot` folder.
* Compile and run.
